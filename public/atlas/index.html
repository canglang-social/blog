§1 · the vocabulary

Five primitives, one anatomy

A prompt is stored text — raw material. A command is the thin loader that deploys it as fixed steps. A command usually wears a role — a standing identity with judgment and boundaries. A workflow is the recurring loop that composes all three; a project is the built thing that comes out the other end.

§2 · where judgment lives

Four judgment-roles

Roles appear where judgment concentrates; commands suffice where the task is procedural. That is why the system is mostly workflows + commands with exactly four roles — and why /scout or /tailor never needed a persona. The Chief audits the other three from outside — chief, not auditor of its own doing.

Chief of Staff

Owns the inventory and the meta-calls: keep, merge, automate, retire; which tool for a role. Advises first, never touches; on Felix's confirmation, executes via worktree branch + draft PR — or better, delegates to the owning workflow with a brief.

home: ai-chief-of-staff · chief-of-staff.md

Librarian

Owns vault conventions, drift cleanup, and the mobile capture pipeline (Siri → [[inbox/mobile]] → [[inbox]]). Conventions, not content — producer loops own what they append; the vault is a sink.

home: the vault itself · [[Wiki/Librarian]] + [[Wiki/Conventions]]

Editor

Owns blog voice and style, the draft pipeline, /writing curation, and the language policy: one language per published page, always a native-English refine pass. Critiques and refines — never ghostwrites.

home: blog · editor.md (staged 2026-07-07)

Brand Coach

Owns public image and charisma (positioning, image pillars, per-platform bios), social-media strategy, and the outside-in surface audit — a recruiter's eyes on how it all comes across. Drafts frames; Felix writes the words. Routes blog-copy fixes to the Editor.

home: staged in ai-chief-of-staff · brand-coach.md (2026-07-07)
