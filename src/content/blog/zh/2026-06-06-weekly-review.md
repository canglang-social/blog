这是我主动找工作的第一周，也是我的第一次每周回顾。我没有正式设定目标，但脑子里有一张清晰的清单：起草简历、更新领英、为作品集启动一个 agent 项目、测试英语、健身、整理目标岗位清单。到了周六，那个规律已经无法忽视——我完成的都是容易的任务，而最重要的两件，一件都没开始。

完成了的，我都完成得不错：两个版本的简历、更新的领英、四次记录在案的训练，还有一次给了我诚实基准的雅思考试。但我也抓到自己在简历上投入过头——一遍又一遍地开会话去"打磨"一件已经做完的事——而 agent 项目和 JD 清单却原封不动。这种反差就是这周的功课。我不是靠什么都不做来逃避工作，而是靠忙于更容易的事来逃避。

底下藏着的东西更简单也更难：我在回避关于未来的真实决定，因为决定意味着放弃可能性。只要我不选定一个项目或一家目标公司，每个选项就都还活着，也没有什么可以被评判。但一个一直开着的"可能性"什么都产生不了。唯一能创造真实选项的——真实的面试、真实的项目——是一个决定，哪怕不完美。

这一周确实给了我可用的证据。健身习惯能坚持，靠的是两件事：低阻力（离家近）和即时回报（努力的感觉）——恰恰是我找工作的任务所缺的。在咖啡馆工作带来了真实的产出，而在家工作只带来了沙发。这不再是猜测，而是关于我真实运作方式的数据。

所以下周是围绕"行动"而非"优化"来安排的。每天出门。开始 agent 学习——先看中文翻译版，破掉那个让我当场卡死的"我应该读英文"的惯性。用 LangGraph 构建项目，build in public，而第一步具体到我无法躲在它后面：周一在 GitHub 上创建仓库。列出至少二十个目标岗位。重点不是把每扇门都开着——而是走进其中一扇。
